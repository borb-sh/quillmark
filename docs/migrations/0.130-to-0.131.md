# 0.130 → 0.131 — font family in richtext, and a host font library

A writer sets a run of richtext in a font family, spelled in markdown as a
`qm-font` pair, and an app hands the engine a font library of its own to
choose families from. The first two sections are the changes no type checker
reports; the table closing the guide lists every break.

## Stored rows

**A row holding a `font_family` mark saves under `quillmark/document@0.131.0`**,
the first tag that can hold one. Every other row saves under `@0.129.0` as
before, byte for byte, so a 0.130 build reads it and a hash over its bytes
holds. A 0.130 build refuses a row under the new tag, as a build too old for
it, so deploy every reader before a writer saves a font mark.

## Markdown

**`<qm-font family="Carlito">text</qm-font>` inside a line sets its text's
family, where 0.130 dropped the tags and warned `parse::dropped_construct`
(`qm-font`).** Markdown that spelled one now imports with a font mark and
renders in that family. Pairs nest, and the outer family resumes past an inner
pair. An attribute other than `family` drops alone and warns
`qm-font[<name>]`. A tag setting no family, or a pair left open, drops and
warns `qm-font` as before. A `qm-font` tag line, which 0.130 read as an
element named `font` around the blocks below it, drops and warns `qm-font`, and
the blocks stay.

[Markdown Syntax](../authoring/markdown-syntax.md#font-family) has the full
rules.

## Rendering

A Typst render sets a font run's family ahead of the font list in force, so a
character the family lacks falls through to the surrounding font. A family no
loaded font holds keeps the surrounding font and warns
`typst::unknown_font_family` once per family and field, at the field's path,
on every compile. Code spans and equations keep their own font. An acroform
render ignores the mark.

An app adds fonts through the engine: `Engine::with_fonts(files)`, the
`fonts` option of `new Engine(..)` in JavaScript, `Engine(fonts=..)` in
Python, and `--font` on `quillmark render` and `quillmark workspace`. A
session reads the quill's own fonts first, then the library's, then the
embedded Roboto, which loads only for a quill shipping no fonts. A file other
than `.ttf`, `.otf`, `.ttc` or `.otc` fails the engine with
`engine::font_unsupported`, and one holding no face Typst reads with
`engine::font_unreadable`. `engine.fontFaces(quill)` lists the faces a session
of the quill sets type in, with their bytes.

## Every break

| Break | Surface | Action |
|---|---|---|
| A row holding a `font_family` mark saves as `quillmark/document@0.131.0`, which a 0.130 build refuses | stored documents | Ship readers before writers |
| An inline `qm-font` pair imports as a `font_family` mark, where it dropped and warned `qm-font` | imported content, rendered output, `Parsed.warnings` | None |
| A `qm-font` tag line drops and warns `qm-font`, where it opened an element named `font` | imported content, `Parsed.warnings` | Set the family with an inline pair inside each line |
| `parse::dropped_construct` names `qm-font[<attr>]` for an attribute a `qm-font` pair cannot read | `Parsed.warnings`, `doc.warnings`, revise warnings | Drop the attribute, or let the warning stand |
| A font run in a family no session font holds warns `typst::unknown_font_family` | Typst session warnings, `RenderResult.warnings` | Supply the family, or treat the code as an error where a hard failure is wanted |
| `MarkKind` gains `FontFamily { name }`; `StoredDocument` gains `V0_131_0`, and `STORAGE_V0_131_0` is the tag a row holding a font mark saves under | Rust | An exhaustive `match` adds the arm |
| `ContentMark` gains a `font_family` member | WASM | A `switch` over `type` handles it |
| `TypstBackend` is a struct holding a font library: the unit value `TypstBackend` is `TypstBackend::default()`, or `TypstBackend::new(Arc<FontLibrary>)` | Rust | Construct it |
| `quillmark_typst::workspace::workspace` takes a `&FontLibrary` third | Rust | Pass `&FontLibrary::default()` for no library |
| A refused font in `new Engine({ fonts })` rejects the engine's first verb | WASM | Catch the rejection |
| `quillmark workspace --font` writes `fonts/host-<n>.<ext>` beside the quill's fonts | CLI | None |
