# 0.114 → 0.115 — an island stores its value, not its provenance

The break no type checker reports leads: **canonical content bytes move for any
document holding an island.** The `loss` key leaves the island form, so a stored
row's bytes, and any content hash or cache key computed over them, recompute on
the next save. The schema tag does not change and no stored row needs migrating:
a row written with the key opens here, the key ignored, and comes back without
it. No rendered output moves — nothing rendered from the class.

| Break | Surface | Action |
|---|---|---|
| `loss` leaves an island's canonical form, which is `{id, type, props}` | storage JSON, content hashes | Re-baseline a byte snapshot or hash keyed on stored content. Rows carrying the key still open |
| `ContentIsland.loss` and `ContentLossClass` are gone | WASM / TypeScript | Drop the field from island literals. A `loss` still spelled on an authored island or an `islandOps` entry is ignored, not refused |
| `Loss`, `Island::loss`, `Island::with_loss` and `IslandType::default_loss` are deleted | Rust | Build an island from `{id, island_type, props}`; a destructure of `Island` loses an arm |
| `island loss` leaves the closed vocabularies, which are four | storage JSON, both lanes | None. A row spelling a class outside the built-ins opened as `ParseError::UnknownName { axis: "island loss", .. }` and opens plainly now |

## Why the class goes rather than grows

One import minted a class other than `lossless`: a table cell holding an inline
image, whose alt text lands as the cell's text and whose url lands nowhere.
That is a fact about the import, not about the island it mints. A cell written
`| a cat |` and a cell written `| ![a cat](cat.png) |` mint the same `props`,
and the markdown projection has no syntax to tell them apart on the way back
out — so the class survived neither a `to_markdown` → `from_markdown` hop nor
re-derivation from the row that carried it, and the content fixed point had to
be stated modulo it.

Nothing in the engine read it either: export dispatches on an island's `type`,
the Typst emitter and the acroform binder never looked, and an `islandOps` `set`
stored whatever class the op named. What is left is a per-island annotation that
the content model guarded as an invariant it could not check. The guard goes with
it: the closed vocabularies now cover the four discriminators a projection
dispatches on (line `kind`, container, mark `type`, island `type`), and a row is
no longer refused over a field no reader consumed.

A host that surfaced the annotation to a user surfaces the drop at the import
instead, where the markdown it is about is still in hand. A row read later cannot
say what its markdown once held.
