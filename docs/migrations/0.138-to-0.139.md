# 0.138 → 0.139 — the typed writer refuses an undeclared member

## Writing a document

`TypedWriter::set`, `set_all` and `add_card`, and `CardWriter::set` and `set_all`, refuse a member that a typed dictionary's `properties` or every world of a variant-bearing enum leaves undeclared, as they refuse an undeclared field. The error is `edit::unknown_field`, its path at the member, as `main.classification.level`. Such a write stored the member, where nothing drew or rendered it.

```yaml
classification:      # refused: `level` is no world's member
  level: CUI
  controlled_by: 123 CS/SCX
classification:      # lands
  value: CUI
  controlled_by: 123 CS/SCX
```

A member the stored value already carries, with the same value, passes, so a write that reads a container and writes it back with one member changed still lands over input an older schema declared. A member of a world the discriminant does not select is declared and lands, as before. `Quill::conform`, the render and the opaque `store_field` are unchanged.
