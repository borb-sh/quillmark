# Migration Guides

A release that breaks the document syntax, the plate-JSON wire format, or a
public API ships a guide for that version step. So does a release that moves the
embedded Typst to a new minor version, since a plate is Typst source: its guide
names the new Typst version and links that version's changelog, even when no
plate in this repository changed. Most breaks are hard cutovers —
the old form stops parsing or compiling — so the guide is the path forward, not
an optional read.

Each guide covers one step. To cross several versions, work through them in
order; each states its own breaks in full. The rows below name the step's
headline break, enough to pick the guide.

A stored row loads across every step but two: 0.125 → 0.126 refuses a body nested past 12 levels or a `$quill` its narrowed grammar refuses, such as the lone major `memo@1`, and 0.129 → 0.130 a row under any tag older than `quillmark/document@0.124.0`. Each guide says how to rewrite such a row before upgrading. The storage DTO's bytes and tag hold across every step here except 0.123 → 0.124, 0.128 → 0.129, 0.130 → 0.131, 0.133 → 0.134 and 0.134 → 0.135, where canonical bytes move (content hashes recompute) and the tag becomes `quillmark/document@0.124.0`, `@0.129.0`, `@0.131.0`, `@0.134.0` and `@0.135.0` in turn. At 0.130 → 0.131 a row holding a table's `headless: true` loads it with `head: 0` beside it, a body mark over a line break as one mark per line, and overlapping links as one link per character, at 0.131 → 0.132 one holding a `term` line or a `description` or `element` container loads as what it held, and at 0.135 → 0.136 one holding an anchor whose id opens with `~` loads it as transient; each rewrites once when saved, under the same tag. At 0.132 → 0.133 a row holding a table on a line it shares with prose loads as stored, where it loaded with the line broken. A build older than a step that moves the tag refuses a row the newer build has rewritten.

The guides for steps up to 0.123 are in the repository at [v0.140.0](https://github.com/birdorbs/quillmark/tree/v0.140.0/docs/migrations).

## Guides

| Step | What changes |
|---|---|
| [0.141 → 0.142](0.141-to-0.142.md) | An unquoted value resolves by the YAML 1.2.2 core schema: `0012`, `1.50` and `0x1F` are numbers, not the text written, and YAML 1.1's `0b11` and `1_000`, `0X1F` and `-0x1F` are strings, which a `number` or `integer` field refuses, in a document and through the typed writer. |
| [0.140 → 0.141](0.140-to-0.141.md) | A `text` or `richtext` field declaring `multiline:` fails to load as `quill::field_parse_error`, whose hint names `shape:`, and `quill::deprecated_multiline` is no longer emitted. `schema()` no longer carries `multiline` beside `shape`, nor the transform schema `quillmark:multiline` beside `quillmark:shape`, and `QUILLMARK_MULTILINE_KEY` is removed. `quillmark_docx::lower` no longer exports its `CODE_*` constants; each code is `quillmark_docx::notice::Code::<Variant>.as_str()`. An unquoted value such as `0012` or `0x1F` is held as the text written, so a `text` field prints it as written and a parsed field value is a string until a quill coerces it. |
| [0.139 → 0.140](0.139-to-0.140.md) | A quill declares `main` and each card kind as peers of one `schema:` block; a top-level `main:` or `card_kinds:` section fails as `quill::unknown_section`. `quill.schema` is keyed by kind, with no `card_kinds` level. `ui.layout: flat` is refused as `quill::field_parse_error`. `type: plaintext`, `type: string`, `inline:` and `ui.multiline` fail with the generic unknown-type or unknown-key message. An acroform quill holding `form.json` or `form.yaml` and no `Form.yaml` fails as `acroform::missing_form_spec`. `OutputFormat` gains `Docx`, which every Typst quill lists. |
| [0.138 → 0.139](0.138-to-0.139.md) | The typed writer refuses a member a typed dictionary or every world of a variant-bearing enum leaves undeclared, as `edit::unknown_field` at the member, unless the stored value already carries it, equal. |
| [0.137 → 0.138](0.137-to-0.138.md) | A newline inside a paragraph is a line break, where it was a space, in the body and in every `richtext` value, and export writes one as a newline. A `text` or `richtext` field declares `shape: line`, `lines` or `blocks` where it declared `multiline`, which loads one more release with a `quill::deprecated_multiline` warning. In a `line` or `lines` field, list, heading and quote syntax prints as typed. `true`, `false`, `null`, `.inf` and `.nan` read as such only all lowercase, capitalized or all uppercase: `tRue`, `nUlL` and `.iNf` are the text written, a word under a `boolean` field fails as `validation::type_mismatch`, and nothing else reports the change. |
| [0.136 → 0.137](0.136-to-0.137.md) | acroform boxes with an `option:` stamp as one radio field whose value is the enum value, bound fields naming one `schema_field` stamp as one field named by the first, and `option: Off` is refused. `quillmark_pdf::FieldType` gains `Radio`, and `stamp` makes specs sharing a name one field. |
| [0.135 → 0.136](0.135-to-0.136.md) | An anchor whose id opens with `~` is transient: the live document carries it, but storage, the annotated read and every hash leave it out, and `@quillmark/wasm` exports `TRANSIENT_ANCHOR_PREFIX`. Public Rust API nothing called is gone: `document::lost_construct` and the code `export::lost_construct`, `Document::set_card_kind`, `Card::store_fields`, `backend::fit_raster_scale`, `ids::Minter::new` and `Repair::dropped_anchor`. |
| [0.134 → 0.135](0.134-to-0.135.md) | The content engine's breaking release. A write fills `?` placeholders, naming them in the receipt's `minted`; the structural edits are `Document` verbs answering a `Receipt`, beside `diffRange` and `blockAt`. A write takes a value only in its canonical form, a stored one reads leniently for this release with `content::noncanonical_read`, and a table cell and a footnote's note are each one paragraph. A field's content stores canonical, the schema-free writes are `doc.unchecked.storeField` / `insertCard`. Core is single-writer: a stale base refuses with `edit::stale_base`, where it rebased, and late writers merge through `@quillmark/collab`. The anchor step places or moves (`move: true`); `repair` answers its change; `movedAnchors` carries a `reason`; the writer's revise answers the content `Receipt`; a `text` field is stored as `codec: "plain"` content. Storage writes `quillmark/document@0.135.0`, a line-form value loads migrated and warns `content::noncanonical_read` so a resave rewrites it, and a content value or change holding a key its shape does not define is refused. |
| [0.133 → 0.134](0.133-to-0.134.md) | Content v2: every body and `richtext` value is the content model, with blocks, containers, anchors and island slots carrying ids, in storage under `quillmark/document@0.134.0`, the `Card` wire and every read. Offsets in content values and changes cross WASM in UTF-16 code units, where they counted scalar values. `Document` gains `read`, `apply`, `revise` and `replace`, each answering a `Receipt` and taking the `base` hash the writer read; `overwrite`, `reviseContent`, `applyChange`, `mapMarks` and `mapPos` are removed, and so is the line form's `ChangeBundle` op lane. Every composable card carries a `$id`, which `to_markdown` writes after its `$kind`. Python's `writer.revise_body`, `revise_field` and `revise_document` return a dict receipt, where they returned a list of `Diagnostic`: a loop over the result runs over its keys without failing, so read `receipt["warnings"]`, the same `Diagnostic` objects. The dict carries `dropped_anchors`, and `from` on the document revise. `Revised` gains `dropped_anchors`, and WASM's revise receipts `droppedAnchors`. A table cell's anchor is listed, carried and reported as the prose's. |
| [0.132 → 0.133](0.132-to-0.133.md) | The blueprint is retired: `quill.blueprint`, `QuillConfig::blueprint()` and `quillmark blueprint` are deleted, and a model writes the JSON authoring document instead, read through `authoringSchema` and imported with `fromAuthoring`. `build_transform_schema` takes a `SchemaCodec`, `quillmark validate` renders the empty and seeded documents only, and a multi-line `description:` or an enum member holding `>`, `;` or `\|` loads. A root `example.md` is an ordinary file: `quillmark validate` and `example_document()` no longer read it, and a quill's example is derived from the `example:` its fields declare and the `body.example` its kinds declare, so move each value onto its field. `example:` returns at any depth, checked as `default:` is under `quill::example_*`, and a body takes `description` and `example`. `schema()` and the authoring schema expose them. `Quill::example_document()` returns `Option<Document>`, the bindings no longer throw from it, `EXAMPLE_FILE` and `quill::example_reference` are deleted, and `FieldSchema` and `BodyCardSchema` gain public fields. Normalizing content moves no text: a table's slot sharing its line with prose stays there, where the mint broke the line around it, and markdown export breaks it instead. `overwrite` takes the shape where it threw `block island in a line's prose`, a `Set` on such a table lands, and Typst sets the table as a block in place. WASM gains `normalize(content)`, the form `overwrite` stores. |
| [0.131 → 0.132](0.131-to-0.132.md) | A `qm-<name>` element such as `qm-keep` imports as what it wraps, its open tag warning `parse::dropped_construct`, and a definition list as one paragraph; a stored row holding either loads as what it held and saves without it. The Typst helper's `elements` registry and `typst::unregistered_element` are gone, so a plate calling `qm.elements.update(..)` fails to compile until the call goes. `LineKind::Term`, `Container::Description` and `Container::Element` are gone, as are the WASM `term`, `description` and `element` members. Every Typst PDF carries a title: the render's new `title` option, else the plate's, else the quill's `description`. |
| [0.130 → 0.131](0.130-to-0.131.md) | A `qm-span` pair inside a line sets its text's font family, where it dropped, and a row holding one saves as `quillmark/document@0.131.0`, which a 0.130 build refuses. A family the host library lacks warns `typst::unknown_font_family`. An app adds a font library through `Engine::with_fonts`, the WASM `fonts` option, `Engine(fonts=)` or `--font`. In Rust, `MarkKind` gains `FontFamily`, `TypstBackend` is constructed, and `workspace` takes a `&FontLibrary`. `qm-table` and `qm-cell` no longer spell a table's layout, so markdown written with either loses it: rewrite such a table as HTML. A table holding widths, a placement, a cell alignment, a merged cell or other than one header row exports as an HTML table, and an HTML `<table>` block imports as a table. A stored `headless: true` gains `head: 0` beside it, which a 0.130 build ignores, and a cell's `colspan` and `rowspan` span it. A table holds at most 100 000 cells: import drops the rows past it, and a stored table past it is refused. A body mark over a line break loads as one mark per line, and `link` is keyed, so a character holds at most one link. |
| [0.129 → 0.130](0.129-to-0.130.md) | A stored row tagged `quillmark/document@0.81.0` through `@0.116.0` fails to load as an unknown schema version: only `@0.124.0` and `@0.129.0` are read. Resave every older row with a 0.124 to 0.129 build before upgrading. |
| [0.128 → 0.129](0.128-to-0.129.md) | A footnote reference and its definition render a footnote, where the definition dropped and the reference stayed text, and `$…$` and `$$…$$` render equations, where they were text: each imports as an island, `footnote` and `math`, so a save writes `quillmark/document@0.129.0` and a 0.128 build refuses the row. Escape a dollar, `\$`, to keep it text. A paragraph with a `: description` line under it renders a definition list, a `term` line and a `description` container; escape the colon, `\:`, to keep it text. The Typst backend translates TeX to Typst math, warning `typst::unsupported_tex` for a command it does not lower, and embeds Noto Sans Math for a quill shipping no math font. `schema()` no longer writes `ui.layout: flat` on an object alone in a legacy `ui.group`, `ui.layout: flat` warns `quill::deprecated_flat`, and a card-level field outside every group declared after a top-level `object` warns `quill::field_after_object`. |
| [0.127 → 0.128](0.127-to-0.128.md) | A quill whose `requires` floor is above the running release fails to load as `quill::requires_unmet`, where it failed as `quill::engine_too_old`, and a host matching the old code stops matching. The Rust struct and Python class `Quillmark` are `Engine`, the name JavaScript already carries, with no alias, so `use quillmark::Quillmark` fails to compile and `from quillmark import Quillmark` fails to import. |
| [0.126 → 0.127](0.126-to-0.127.md) | An acroform quill's field spec is `Form.yaml`: one holding `form.yaml` fails to open as `acroform::legacy_form_yaml`, so no acroform quill opens on both releases. An acroform quill whose `Form.yaml` gives a field a box with no width or height, or one wholly off its page, fails to open as `acroform::invalid_field_rect`, where it opened and showed that field's value nowhere. |
| [0.125 → 0.126](0.125-to-0.126.md) | A `.ttc` or `.otc` font collection a quill ships loads every face it holds, up to 256, where the backend skipped it, and a quill whose only fonts are collections no longer renders in the embedded Roboto. The `status_report` fixture is `0.2.0`, its `state` storing `on_track` / `at_risk` / `blocked` where it stored display text. A `javascript:`, `vbscript:`, `data:` or `file:` link renders as its text, and a card-yaml block whose alias expansion outgrows its own size fails to parse. A body nests at most 12 levels deep, where it nested 100, and one past it fails `parse::body_import` at the body's `path`. A WASM trap rejects as `runtime::backend_trapped`. A `$quill` name may carry a collection, `borb.usaf_memo@1.2`, and no longer starts with `_` or runs past 64 characters. A quill declaring a field named `body` fails to load with `quill::reserved_field_name`. An acroform quill's field spec is `form.yaml`: a `form.json` fails as `acroform::legacy_form_json`, and `invalid_form_json` / `missing_form_json` are `invalid_form_spec` / `missing_form_spec`. A Typst quill's plate is `plate.typ` by name: a quill holding it and declaring no `typst.plate_file` renders it, where it rendered a blank page, and nothing reports the change; a quill with neither fails as `typst::plate_missing`; and a `typst:` key other than `plate_file` fails the load as `quill::unknown_backend_key`, where it warned `typst::unknown_key`. A card declaring `sections:` fails `quill::invalid_card_schema`: a card groups fields under a top-level `object`, which documents and plates address. A blueprint's `$kind: main` line no longer falls back to `quill.description`. A `$quill` selector is `@MAJOR.MINOR` or exact, so `name@1` fails `parse::invalid_quill_reference` and a stored row holding it fails to load, a document the quill creates pins `name@1.2` where it pinned `name@1.2.0`, and a quill's `version` is `MAJOR.MINOR.PATCH`, so `version: "1.2"` fails `quill::invalid_version`. A blueprint prints a blank `default:` as an empty cell, and a defaultless typed table as `[]`, or an empty cell where optional, under its commented-out row. `type: plaintext` is `type: text`, `type: string` is retired in favor of `text`, read by a plate as a `str` through `qm.str(..)`, and `inline:` and `ui.multiline` give way to `multiline:`, one line being the default, so no quill declaring a text field loads on both releases, and a stored `string` value holding an interior line break fails to render; `schema()` carries `multiline` where it carried `inline: true`, and the transform schema a plate reads `quillmark:multiline` where it carried `quillmark:inline`. |
| [0.124 → 0.125](0.124-to-0.125.md) | A value a Typst plate prints itself, `#data.subject` included, surfaces no region: a field prints through `qm.ink` or sits in a `qm.region` claim, and `quillmark check --regions` lists what no click reaches. No dictionary carries `$ink`, every typed dictionary carries `$path`, and `typst::unclosed_field_region` is `typst::unclosed_region`. The helper is version 0.2.0, imported `as qm`, any other import failing as `typst::helper_import`; `field-region` is `qm.region`, and `ink(x).f` and `display(..)` are `qm.ink(x, "f", ..)`. `Quill::validate` warns `backend::declined_construct`, the render's own diagnostic, where it warned `validation::declined_construct`, and draws none for a document the render floor refuses. A typed `set` / `setAll` returns the `parse::dropped_construct` of each `richtext` string it writes, and `addCard` its fields' ahead of its body's. A table `align`, `widths` or `headless` outside its set rests as written and reads as absent, where normalization removed it. `droppedAnchors` holds `DocumentAnchor`s with their `line`, matched at the exact address. A backtick fence opener whose info string holds a backtick opens no fence for the card scanner, and a raw tag inside a footnote definition warns nothing beside the `footnote`. A placed table aligns its cells as an unplaced one does. A card's fields go in titled panels under `sections:`; `ui.group` warns `quill::deprecated_groups`, and a grouped card lists its fields in display order. `ImportWarning` is a struct, `Container::Element` holds a `carrier::Element`, the typed writer's `set` / `set_all` return `Vec<Diagnostic>`, and `SessionHandle::update` takes the session's `QuillConfig`. |
| [0.123 → 0.124](0.123-to-0.124.md) | An HTML block drops as CommonMark reads it, now with a warning, and a line holding only element and `qm-table` tags reads as a tag line wherever it stands. A fenced block holding `<!-- a --> b` keeps its line, text after a block nested in a tight list item opens its own line, and a line holding only tags on the line after a table's rows ends the table. `- [ ]` and `- [x]` render a box, ticked for `[x]`, and a footnote definition drops with a warning, where it silently defined a link. A raw tag a markdown import drops warns `parse::dropped_construct` at its body, on `doc.warnings`, and `quillmark validate` fails an `example.md` holding one; a one-shot render's `RenderResult.warnings` no longer carries `doc.warnings`, and in WASM a JSON `null` inside a returned value crosses as `null`, where it crossed as `undefined`. A `</u>` closes the innermost open `<u>` across `**`, an unclosed `<u>` drops where its text ends, and export writes `<u>` outside the delimiters. `from_markdown` returns `Imported { content, warnings }`. A revise returns `Revised { delta, warnings }`, where it returned the `Delta`, and `add_card` its body's warnings; WASM `importMarkdown` returns `{ content, warnings }`, and Python's `revise_body` / `revise_field` / `add_card` return the warnings. `Quill::validate` warns `validation::declined_construct` at a field holding a construct the backend declines, an image under Typst, and an acroform render warns `backend::declined_construct` for every construct but the paragraph. A `qm-table` wrapper lays out its table, a `qm-*` element is stored content rendered through the plate's `elements` registry, and a save writes the storage tag `quillmark/document@0.124.0`. A revise keeps the id of each island it leaves unchanged or edits in place. Text after a card-yaml block's root value, and a mapping holding two keys of one text such as `1` and `"1"`, fail the parse where they dropped. `quillmark validate` reports a bad `typst.plate_file` under the render's `typst::plate_*` codes, where it raised `cli::plate_file_*`. A base PDF with hybrid cross-reference data fails as `pdf::xref_stream`. A WASM options object, `Addr` or `CardInput` inheriting an unknown key from a null-prototype object throws. |
