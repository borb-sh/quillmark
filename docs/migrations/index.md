# Migration Guides

A release that breaks the document syntax, the plate-JSON wire format, or a
public API ships a guide for that version step. So does a release that moves the
embedded Typst to a new minor version, since a plate is Typst source: its guide
names the new Typst version and links that version's changelog, even when no
plate in this repository changed. Most breaks are hard cutovers —
the old form stops parsing or compiling — so the guide is the path forward, not
an optional read.

Each guide covers one step. To cross several versions, work through them in
order; each states its own breaks in full. The rows below name the step's
headline break, enough to pick the guide.

A stored row loads across every step but three: 0.112 → 0.113 refuses a
host-authored content name, 0.125 → 0.126 a body nested past 12 levels or a
`$quill` its narrowed grammar refuses, such as the lone major `memo@1`, and
0.129 → 0.130 a row under any tag older than `quillmark/document@0.124.0`. Each
guide says how to rewrite such a row before upgrading. The storage DTO's bytes
and tag hold across every step here except 0.111 → 0.112, 0.114 → 0.115,
0.115 → 0.116, 0.123 → 0.124, 0.128 → 0.129 and 0.130 → 0.131, where canonical bytes move
(content hashes recompute) and the tag becomes `quillmark/document@0.112.0`,
`@0.115.0`, `@0.116.0`, `@0.124.0`, `@0.129.0` and `@0.131.0` in turn. At
0.122 → 0.123 a row holding a comment that ends in whitespace loads without
it, and at 0.130 → 0.131 one holding a table's `headless: true` loads it as
`head: 0`; each rewrites once when saved, under the same tag. A build older than a step that moves the tag refuses a row
the newer build has rewritten.

| [0.130 → 0.131](0.130-to-0.131.md) | A `qm-span` pair inside a line sets its text's font family, where it dropped, and a row holding one saves as `quillmark/document@0.131.0`, which a 0.130 build refuses. A family the host library lacks warns `typst::unknown_font_family`. An app adds a font library through `Engine::with_fonts`, the WASM `fonts` option, `Engine(fonts=)` or `--font`. In Rust, `MarkKind` gains `FontFamily`, `TypstBackend` is constructed, and `workspace` takes a `&FontLibrary`. `qm-table` and `qm-cell` no longer spell a table's layout, so markdown written with either loses it: rewrite such a table as HTML. A table holding widths, a placement, a cell alignment, a merged cell or other than one header row exports as an HTML table, and an HTML `<table>` block imports as a table. A stored `headless: true` normalizes to `head: 0`, and a cell's `colspan` and `rowspan` span it. A table holds at most 100 000 cells: import drops the rows past it, and a stored table past it is refused. |

Escape a dollar, `\$`, to keep it text. A paragraph with a `: description` line under it renders a definition list, a `term` line and a `description` container; escape the colon, `\:`, to keep it text. The Typst backend translates TeX to Typst math, warning `typst::unsupported_tex` for a command it does not lower, and embeds Noto Sans Math for a quill shipping no math font. `schema()` no longer writes `ui.layout: flat` on an object alone in a legacy `ui.group`, `ui.layout: flat` warns `quill::deprecated_flat`, and a card-level field outside every group declared after a top-level `object` warns `quill::field_after_object`. |
| [0.127 → 0.128](0.127-to-0.128.md) | A quill whose `requires` floor is above the running release fails to load as `quill::requires_unmet`, where it failed as `quill::engine_too_old`, and a host matching the old code stops matching. A `$quill` selector is `@MAJOR.MINOR` or exact, so `name@1` fails `parse::invalid_quill_reference` and a stored row holding it fails to load, a document the quill creates pins `name@1.2` where it pinned `name@1.2.0`, and a quill's `version` is `MAJOR.MINOR.PATCH`, so `version: "1.2"` fails `quill::invalid_version`.
