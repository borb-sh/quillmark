# 0.133 → 0.134 — Python's revise verbs return the whole receipt; a revise names the anchors it drops

## Python's revise verbs return a dict

The break no type checker reports: **`writer.revise_body`, `writer.revise_field` and `writer.revise_document` return the receipt as a dict, where they returned a list of `Diagnostic`.** A loop over the result iterates the dict's keys, so `for w in writer.revise_body(md)` runs over `"delta"`, `"warnings"` and `"dropped_anchors"` without failing, and `writer.revise_field(name, md) == []` is `False` on every call. The warnings are the dicts `quill.validate` returns, read `w["code"]` where `w.code` read a `Diagnostic`.

```python
# 0.133
for w in writer.revise_body(markdown):
    print(w.code, w.path)

# 0.134
receipt = writer.revise_body(markdown)
for w in receipt["warnings"]:
    print(w["code"], w["path"])
```

| Verb | 0.133 returned | 0.134 returns |
|---|---|---|
| `revise_body(md, card=)` | `list[Diagnostic]` | `{"delta": {"ops": [...]}, "warnings": [dict, ...], "dropped_anchors": [{"id", "line"}, ...]}` |
| `revise_field(name, text, card=)` | `list[Diagnostic]` | the same shape, its warnings at the field |
| `revise_document(md)` | `list[Diagnostic]` | `{"dropped_anchors": [{"id", "path", "line"}, ...], "warnings": [dict, ...], "from": [int \| None, ...]}` |

`dropped_anchors` names each comment anchor the write dropped, and `from` the stored card each revised card revises, `None` for an inserted card. Both are the receipts WASM's `reviseBody`, `reviseField` and `reviseDocument` already return.

## A revise names the anchors it drops

**`Revised` gains `dropped_anchors`**: every prose anchor of the stored value whose id the revised value holds nowhere, each an `AnchorRead { id, line }`. `Card::revise_body`, `revise_field`, `revise_body_content`, `revise_field_content` and the typed writer's `revise_body` / `revise_field` fill it. `Revised` is `#[non_exhaustive]`, so a pattern already carries `..`. WASM's `Revised` gains `droppedAnchors: { id, line }[]` on `doc.revise`, `doc.reviseContent`, `writer.reviseBody` and `writer.reviseField`.

New, with nothing to migrate: the comment-anchor handle. `Document::anchor_contexts` / `anchor_context(id)` read each anchor's `AnchorSelector { id, path, quote, prefix, suffix }`, and `Document::reattach(selectors, deltas)` places a dropped anchor again where its quote is found once with its context agreeing, returning `Reattached { reattached, orphaned }`. WASM spells them `anchorContexts`, `anchorContext` and `reattach(selectors, deltas?)`, Python `anchor_contexts`, `anchor_context` and `reattach(selectors, deltas=None)`. The content crate's `anchor` module holds the per-field rule: `anchor_contexts`, `locate`, `Content::reattach` and its constants. `Delta::inserted_spans` is public. The facade re-exports `AnchorSelector`, `Reattached`, `AnchorRead` and `DocPath`.

| Break | Surface | Action |
|---|---|---|
| `revise_body`, `revise_field` and `revise_document` return a dict, where they returned `list[Diagnostic]` | Python | Read `receipt["warnings"]`, each a dict |
| `Revised` has a public `dropped_anchors` field | Rust | None for a pattern with `..`; a `Revised { .. }` literal outside the crate was already refused |
| `DocumentRevised.dropped_anchors` no longer names an anchor whose id the revised value holds in a table cell | Rust, WASM, Python | None: a markdown write mints no cell anchor |
