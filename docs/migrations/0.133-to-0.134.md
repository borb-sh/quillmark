# 0.133 → 0.134 — Every card carries an id; Python's revise verbs return the whole receipt; a revise names the anchors it drops

## Every composable card carries a `$id`

The break every consumer sees: **`to_markdown` writes a `$id:` line after each composable card's `$kind`**, and a stored document holding a composable card saves under `quillmark/document@0.134.0`, which a 0.133 build refuses to load.

```markdown
~~~
$kind: indorsement
$id: c3kq9f
from: ORG1/SYMBOL
~~~
```

A card that spells no `$id` is minted one where it is placed: by a parse, by a load of an older row, by `insert_card`. The mint is a fixed sequence, so equal markdown parses to equal ids, and a stored id is never rewritten. An author may write their own, 1 to 64 of `[A-Za-z0-9_-]` opening with a letter or digit; a parse replaces one outside that grammar, or one an earlier card holds, and warns `parse::card_id_reminted`. `$id` on the root block is a parse error, and `$id` never reaches the plate JSON.

What the id buys:

- **A whole-document revise pairs a card by the id it spells** before any text match, so a rewritten or moved card keeps its anchors and `$ext`. A pasted copy that keeps the original's `$id` is an inserted card with a new id. A list field's items now align by text, so an item inserted ahead of an anchored one leaves its anchor in place.
- **A comment selector names its card.** `AnchorSelector` and `DocumentAnchor` gain `card_id` (`cardId` in WASM), and `reattach` finds the card by it wherever it moved, orphaning the selector where the card is gone. A selector stored without one stays path-strict. Remapping a dropped selector's card index through `DocumentRevised.from` is no longer needed.

A durable per-card key carried in `$ext` can move to `$id`.

| Break | Surface | Action |
|---|---|---|
| `to_markdown` emits `$id: <id>` after each composable card's `$kind` | every binding | A test comparing emitted markdown byte-for-byte adds the line, or reads the id from the card |
| A stored row holding a composable card saves under `quillmark/document@0.134.0`; `current_storage_version` returns it | every binding | Upgrade every reader before the first writer; a row of the main card alone keeps its older tag |
| `$id` on the root block is a parse error | markdown | Remove it; the root is `main` |
| `insert_card` refuses a card whose `id` is not a card id or is held by another card (`edit::invalid_card_id`, `edit::duplicate_card_id`) | every binding | Drop `id` from a card copied within one document, so it mints a new one |
| `Card` / `CardInput` gain `id`; `AnchorSelector`, `DocumentAnchor` and the Python dicts gain `card_id` | every binding | A `DocumentAnchor { .. }` literal adds the field; an exact-equality test on a selector or receipt adds it |
| `PayloadItem` gains `Id` | Rust | An exhaustive `match` adds an arm |

## Python's revise verbs return a dict

The break no type checker reports: **`writer.revise_body`, `writer.revise_field` and `writer.revise_document` return a dict receipt, where they returned a list of `Diagnostic`.** A loop over the result iterates the dict's keys, so `for w in writer.revise_body(md)` runs over `"delta"`, `"warnings"` and `"dropped_anchors"` without failing, and `writer.revise_field(name, md) == []` is `False` on every call. The warnings are the same `Diagnostic` objects under `receipt["warnings"]`.

```python
# 0.133
for w in writer.revise_body(markdown):
    print(w.code, w.path)

# 0.134
receipt = writer.revise_body(markdown)
for w in receipt["warnings"]:
    print(w.code, w.path)
```

| Verb | 0.133 returned | 0.134 returns |
|---|---|---|
| `revise_body(md, card=)` | `list[Diagnostic]` | `{"delta": {"ops": [...]}, "warnings": [Diagnostic, ...], "dropped_anchors": [{"id", "line"}, ...]}` |
| `revise_field(name, text, card=)` | `list[Diagnostic]` | the same shape, its warnings at the field |
| `revise_document(md)` | `list[Diagnostic]` | `{"dropped_anchors": [{"id", "path", "line"}, ...], "warnings": [Diagnostic, ...], "from": [int \| None, ...]}` |

`dropped_anchors` names each comment anchor the write dropped, and `from` the stored card each revised card revises, `None` for an inserted card. WASM's `reviseDocument` already returned both, and its `reviseBody` and `reviseField` gain `droppedAnchors` in this release.

## A revise names the anchors it drops

**`Revised` gains `dropped_anchors`**: every prose anchor of the stored value whose id the revised value holds nowhere, each an `AnchorRead { id, line }`. An id the revised value holds only in a table cell counts as held, in this receipt and in `DocumentRevised.dropped_anchors`. `Card::revise_body`, `revise_field`, `revise_body_content`, `revise_field_content` and the typed writer's `revise_body` / `revise_field` fill it. `Revised` is `#[non_exhaustive]`, so a pattern already carries `..`. WASM's `Revised` gains `droppedAnchors: { id, line }[]` on `doc.revise`, `doc.reviseContent`, `writer.reviseBody` and `writer.reviseField`.

New, with nothing to migrate: the comment-anchor handle. `Document::anchor_contexts` / `anchor_context(id)` read each anchor's `AnchorSelector { id, path, quote, prefix, suffix }`, and `Document::reattach(selectors, deltas)` places a dropped anchor again where its quote is found once with its context agreeing, returning `Reattached { reattached, orphaned }`. WASM spells them `anchorContexts`, `anchorContext` and `reattach(selectors, deltas?)`, Python `anchor_contexts`, `anchor_context` and `reattach(selectors, deltas=None)`. The content crate's `anchor` module holds the per-field rule: `anchor_contexts`, `locate`, `Content::reattach` and its constants. `Delta::inserted_spans` is public. The facade re-exports `AnchorSelector`, `Reattached`, `AnchorRead` and `DocPath`.

## An export can name what it does not spell

New, with nothing to migrate. `quillmark_content::export::to_markdown_checked` (WASM `exportMarkdownChecked`) returns the markdown with a receipt: each mark, island or run of text the markdown reads back as something else, which core mints as `export::lost_construct` warnings. It reads the markdown back to check it, so call it where the receipt is wanted and `to_markdown` / `exportMarkdown` elsewhere.

## A revise can state what its writer read

New, with nothing to migrate unless you match `EditError` or `BoundParseError` exhaustively. Every revise verb takes an optional base: a hash of the value the writer read refuses a stale write (`edit::stale_base`), and the markdown it read merges its edit onto the change since (`edit::rebase_conflict` where both changed a line). WASM passes `{ baseHash }` or `{ baseMarkdown }` as the last argument, read through `writer.hash()` / `writer.hashAt(addr)` (or `doc.hashAt` for `doc.revise` and `hashContent` for `rebase`); Python passes `base_hash=` or `base_markdown=`, read through `writer.hash()` / `writer.hash_at()`; Rust calls the `*_against` verbs with a `Base`.

| Break | Surface | Action |
|---|---|---|
| `revise_body`, `revise_field` and `revise_document` return a dict receipt, where they returned `list[Diagnostic]` | Python | Read `receipt["warnings"]`, the same `Diagnostic` objects |
| `Revised` has a public `dropped_anchors` field | Rust | None for a pattern with `..`; a `Revised { .. }` literal outside the crate was already refused |
| `revise_import` takes `&Normalized`, where it took `&Content` | Rust | Pass `content.into_normalized()`; a stored or imported content is already one |
| `EditError` gains `Base(BaseError)` and `BoundParseError` gains `Base` | Rust | An exhaustive `match` adds an arm; only the `*_against` revise verbs raise them |
| `Dropped` gains `Bidi`, reported as `parse::dropped_construct` with `construct: "bidi"` | Rust, every binding | An exhaustive `match` adds an arm; a consumer that treats any import warning as fatal now sees one where a bidi control dropped |
| A `*`, `_` or `~~` mark over edge whitespace exports over its text without the whitespace, where it exported as no mark | every binding | None; the markdown keeps a mark it lost |
