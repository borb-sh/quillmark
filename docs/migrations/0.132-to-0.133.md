# 0.132 → 0.133 — normalizing content moves no text

**A table's slot sharing its line with prose is canonical content.** `Content::normalize` broke the line around it, inserting a `\n` on each side; it now leaves the text as given, and the markdown write breaks the line instead. A host whose text lives elsewhere, a CRDT that every client's content must equal included, stores its projection as it is: `overwrite` takes the shape where it threw `block island in a line's prose`, and nothing the mint does changes `text`. The table guide closing this page lists every break.

## Content

**A content holding a table on a shared line keeps that line.** A read after `overwrite`, a stored row's load, an accepted `LineOp::Join` that runs a table's slot into the prose above it: each returns the text as written, where 0.132 returned it with a `\n` either side of the slot and its marks moved past them. Line count and every position after the slot are what the host wrote.

The island lanes still refuse to *place* a table there: an `IslandOp::Insert` whose `at` is not an empty line, and a `Set` retyping an inline island into a table, fail `BlockIslandNotAlone`. A `Set` on a table already sharing its line lands, where it failed the same way.

**`normalize(content)`** is new on the WASM surface, beside `mapMarks` and `rebase`: the content `overwrite` stores from `content`, with no document, throwing where `overwrite` throws.

## Markdown

**`to_markdown` writes a table on a shared line as its own block**, the prose on each side a block of its own, so the markdown reads as 0.132's did and re-imports as the broken content. `to_markdown_annotated` and `anchors_where` read the same broken lines, so an anchor's `line` is the prose on its side of the table.

## Rendering

**The Typst lowering places the table where its slot sits**, inside the paragraph's markup, and Typst sets it as a block between the prose either side. The page draws what 0.132 drew for the broken lines. A table sharing a heading's line sets inside the heading.

## Stored rows

A row holding the shape loads as stored, where 0.132 loaded it broken, and its bytes hold. A 0.132 build reads every row this build writes, breaking the line as it loads. The storage tag holds.

## Every break

| Break | Surface | Action |
|---|---|---|
| A table's slot sharing its line rests there, where normalizing broke the line around it | content reads, stored rows, `overwrite`, `LineOp::Join` | Read positions as written; export markdown for the broken form |
