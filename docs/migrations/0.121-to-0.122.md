# 0.121 → 0.122 — a stamped checkbox carries both its states, a Typst plate at a path Typst refuses fails to open, and a WASM options object refuses a key it does not read

Documents in storage are untouched, and no field value moves. What moves is the
structure of every checkbox the stamp spine writes, in the acroform backend's PDF
and in `quillmark_pdf::stamp` output, and two refusals: a Typst `plate_file` at a
path Typst refuses, and a WASM options key the verb does not read.

The break nothing reports is a **consumer that reads a checkbox's `/AP` `/N` as
one stream**. Every stamped checkbox, checked or not, now carries a dictionary
of both states there, `/Yes` and `/Off`, with `/AS` naming the current one. A
reader that takes `/N` only as a stream finds no stream and draws an empty box
where 0.121 drew the check mark. No error or diagnostic fires. A form filler and
any viewer resolving `/AS` are unaffected, and gain a box they can toggle.

A Typst quill whose `typst.plate_file` names a file the quill holds, at a path
Typst's path grammar refuses, fails to open as `typst::plate_path_invalid`.
Such a path holds a `\`, which Typst refuses on every platform, whether it is a
character in a Unix file name or a Windows separator.

0.121 rendered such a quill, loading its plate as `main.typ`. A `main.typ` the
quill holds then never loaded, and every `#import "main.typ"` or `/main.typ`
reached the plate instead. A plate whose own file name held the `\` drew a
`typst::path_skipped` warning naming it; a Windows `\` separator drew no
warning.

**`engine.render`, `session.render` and `new Engine` throw on an options key
they do not read**, where 0.121 dropped the key and went ahead on the default.
TypeScript flags an unknown key only in an object literal, so an options object
built elsewhere, or any call from plain JavaScript, meets the refusal at run
time. The call that most needs it is `engine.render(quill, doc, { format, today })`,
which rendered the local date in place of the one the caller asked for; it now
rejects.

| Break | Surface | Action |
|---|---|---|
| A stamped checkbox's `/AP` `/N` is a state dictionary, `/Yes` and `/Off`, that `/AS` selects from, where a checked box carried one stream and an unchecked box no `/AP` | acroform PDF output, `quillmark_pdf::stamp` | Resolve `/N` through `/AS`; for a rasterizer that cannot, stamp with `AppearanceStates::Selected` |
| `StampOptions` gains a public field, `states` | Rust | A struct literal spells `..StampOptions::default()` |
| Rendered PDF bytes move wherever a checkbox is stamped | hashes or snapshots of rendered acroform PDFs | Re-baseline |
| A `plate_file` naming a file at a path Typst refuses fails `open` as `typst::plate_path_invalid`, where it rendered with the plate loaded as `main.typ` | Typst quills, diagnostics | Separate `typst.plate_file` with `/`, and rename a plate whose own file name holds a `\` |
| `today` among the render options rejects `engine.render`, where it was dropped and the local date rendered | WASM `engine.render` | Pass the date as the trailing argument: `engine.render(quill, doc, options, today)` |
| A render options key outside `format`, `ppi`, `pages` and `regions` rejects `engine.render` and throws from `session.render` | WASM render calls | Fix the key's spelling, or drop it |
| An `EngineOptions` key other than `backends` throws at `new Engine(...)` | WASM engine construction | Spell it `backends` |

## A stamped checkbox carries both its states

ISO 32000-1 §12.7.4.2.3 gives a check box widget an appearance dictionary naming
its on state and `Off`. The spine writes that shape for every checkbox, whatever
its value:

```
/AS /Off /V /Off
/AP << /N << /Yes 12 0 R /Off 13 0 R >> >>
```

`/Yes` draws the check mark and `/Off` is an empty stream over the same `/BBox`:
the background owns the box, so the mark is all the on state draws. The on-state
name stays `Yes` (`CHECKBOX_ON_STATE`).

A stage that fills the delivered PDF toggles a box by renaming `/AS` and `/V`,
which pypdf and PyMuPDF both do with no appearance to regenerate. In 0.121 that
stage had no state to switch to: a checked box had one stream and an unchecked
box none, so filling a later section meant re-rendering from YAML, which
discards any signature already applied.

A caller of `stamp` handing the result to a rasterizer that draws `/N` without
resolving `/AS` — hayro 0.7, which the acroform canvas uses, is one — stamps
with the new option for that rasterizer:

```rust
use quillmark_pdf::{stamp, AppearanceStates, StampOptions};

let opts = StampOptions {
    states: AppearanceStates::Selected,
    ..StampOptions::default()
};
let preview = stamp(base_pdf, &fields, &opts)?;
```

`Selected` writes each box's `/N` as the one stream its `/AS` names, so the box
draws, but a filler has no other state to switch to: it makes a preview, never a
deliverable. The acroform backend's canvas raster is stamped this way, and
`render()` hands back the `AppearanceStates::All` stamp. The canvas looks as it
did in 0.121.

## A Typst plate at a path Typst refuses fails to open

The plate loads at its declared path, so a module reaches it, and it reaches a
module, by the paths Typst resolves. A path Typst refuses leaves the plate no
name of its own, and any stand-in may belong to a file the quill holds, so the
backend refuses the plate:

```yaml
typst:
  plate_file: lay\out.typ   # typst::plate_path_invalid
```

The refusal fails every surface that reads the plate: a render, a session's
`open`, `quillmark validate`'s render, and `quillmark workspace`. A
`plate_file` naming no file at all stays `typst::plate_missing`, whatever its
spelling.

## An options key the verb does not read throws

```js
// 0.121: renders the local date. 0.122: rejects.
await engine.render(quill, doc, { format: "pdf", today: "2026-03-14" });

// Both: renders 2026-03-14.
await engine.render(quill, doc, { format: "pdf" }, "2026-03-14");
```

A session takes its date once, at `engine.open(quill, doc, today)`, so
`session.render({ today })` throws the same way. A misspelled key fails alike:
`{ fromat: "svg" }` rendered the default format, and `new Engine({ backend })`
kept the bundled build where `backends` would have overridden it.

The refusal is a `QuillmarkError` whose one diagnostic carries no `code`, the
shape a malformed `Addr` or `CardInput` already throws: a call site to fix, not
a condition to route on. Its message names the key, and for `today` where the
date goes.

The first call through each site finds it. To find them ahead of a run, search
the options objects passed to `render` and `new Engine` for a key outside the
ones above, an object spread from a wider config included.
