# 0.121 → 0.122 — render options refuse an unknown key

The break no type checker reports: **WASM render options refuse a key they do
not declare.** `serde_wasm_bindgen` dropped one, so
`engine.render(quill, doc, { format: 'pdf', today: '2026-03-14' })` rendered on
the local date while looking right. `engine.render` and `session.render` now
throw on any key outside `format`, `ppi`, `pages` and `regions`. TypeScript
catches the key only in an object literal, so an options object built
elsewhere reaches the throw at run time.

| Break | Surface | Action |
|---|---|---|
| A render options object carrying a key outside `format`, `ppi`, `pages` and `regions` throws, where the key was dropped | WASM | Pass `today` as the argument after the options: `engine.render(quill, doc, opts, '2026-03-14')`. Delete or correct any other key |
| A `typst.plate_file` Typst's path grammar refuses, such as one holding a backslash, fails at open as `typst::plate_path_invalid`, where the plate loaded under the name `main.typ` | `Quill.yaml` | Rename the plate to a plain relative path |
