# 0.139 → 0.140 — `ui.layout: flat` and lowercase acroform spec names are refused

## `Quill.yaml`

`ui.layout: flat` fails to load as `quill::field_parse_error`, where it loaded with a `quill::deprecated_flat` warning. Drop the key: a card's top-level `object` is its own panel, and a nested one draws as a subform. `table` is the one `layout`.

```yaml
quals:
  type: object
  ui:
    layout: flat      # refused; delete the `ui` block
  properties:
    home: { type: text }
```

A retired spelling reads as any unknown type or key, as `quill::field_parse_error` with the generic message, where it named its replacement. The fixes are those of the release that retired each:

| Retired spelling | Write instead |
|---|---|
| `type: plaintext` | `type: text`, with `shape: lines` where the field takes more than one line |
| `type: string` | `type: text`, read in the plate as a str with `qm.str(..)` |
| `inline: true` | nothing: one line is the default |
| `inline: false` | `shape: lines` or `shape: blocks` |
| `ui: { multiline: … }` | `shape:` on the field itself |

`quill::deprecated_flat` is no longer emitted.

## acroform quills

A quill shipping its field spec as `form.json` or a lowercase `form.yaml` fails to load as `acroform::missing_form_spec` when it holds no `Form.yaml`, where it failed as `acroform::legacy_form_json` or `acroform::legacy_form_yaml`. One holding `Form.yaml` beside either loads, reading `Form.yaml` and ignoring the other file, where it was refused. Rename the file to `Form.yaml`, contents unchanged, and delete any other spec. Neither legacy code is emitted.

## Word export

`OutputFormat` gains `Docx`: `"docx"` in WASM and the CLI, `OutputFormat.DOCX` in Python. The Typst backend lists it in `supported_formats` for every quill, with no change to the quill; the acroform backend does not, and asking it for `docx` fails as any unsupported format does.

| Change | Surface | Migration |
|---|---|---|
| `OutputFormat` gains `Docx` | Rust | Add an arm to an exhaustive `match`: the artifact is one `.docx` file, MIME `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| `OutputFormat` gains `'docx'` | TypeScript | Add a case where a `switch` covers every format |
| `supportedFormats` of a Typst quill lists `docx` | WASM, Python, Rust | A consumer that offers or renders every supported format meets one more |
| `docx` with a page selection fails as `backend::page_selection_not_supported` | all | Render the whole document, as for `pdf` |
