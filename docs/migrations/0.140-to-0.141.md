# 0.140 → 0.141 — `multiline:` refused, and `multiline` gone from the schemas

## `Quill.yaml`

A `text` or `richtext` field declaring `multiline:` fails to load as `quill::field_parse_error`, where it loaded with a `quill::deprecated_multiline` warning; the hint names `shape:`. Declare the shape it meant:

| Was | Now |
|---|---|
| `{ type: text, multiline: false }` | `{ type: text }` |
| `{ type: text, multiline: true }` | `{ type: text, shape: lines }` |
| `{ type: richtext, multiline: false }` | `{ type: richtext }` |
| `{ type: richtext, multiline: true }` | `{ type: richtext, shape: blocks }`, or `shape: lines` where the field holds lines and no list, heading or table |

`quill::deprecated_multiline` is no longer emitted.

## Document Markdown

An unquoted value whose text is not the number YAML reads it as, such as `0012`, `1.50`, `1e3`, `0x1F`, `1_000` or `+15551234567`, is held as the text written. A `text` field prints `0012` where it printed `12.0`, and a document re-emits it quoted, as `"0012"`. A `number` field reads the same number it did, through an alias or a merge too, and an `integer` field reads `0012` and `0x1F` where it refused the first. A value whose text is the number's own, such as `12` or `1.5`, is still a number. A document holding such a value hashes differently from the same markdown parsed before.

| Break | Surface | Action |
|---|---|---|
| A field value spelled as above reads as a string, not a number, before a quill coerces it | a parsed document's field values in Rust, WASM and Python | Read the value through the quill's coercion, or parse the string where a number is wanted |

## Schemas and bindings

| Break | Surface | Action |
|---|---|---|
| A field's declaration view no longer carries `multiline: true` beside `shape` | `schema()` in Rust, WASM and Python, `quillmark schema`, WASM `QuillFieldSchema` | Read `shape`: absent is one line, `"lines"` or `"blocks"` more than one |
| The transform schema no longer carries `quillmark:multiline: true` beside `quillmark:shape`, and the content body carries `quillmark:shape: "blocks"` | Rust `build_transform_schema` | Read `quillmark:shape` |
| `QUILLMARK_MULTILINE_KEY` is removed | `quillmark-core` Rust API | Use `QUILLMARK_SHAPE_KEY` |
| `docs/schemas/quill.schema.json` refuses `multiline` | Editors validating `Quill.yaml` | Declare `shape:` |
| `quillmark_pdf::stamp` returns `Stamped { pdf, warnings }`, where it returned the PDF's bytes; `warnings` holds `pdf::widgets_untagged` when a tagged base's structure tree keeps the widgets out | `quillmark-pdf` Rust API | Read `.pdf`, and carry `.warnings` to the render's |
| `quillmark_docx::lower`'s `CODE_*` constants, `CODE_FONT_NOT_EMBEDDED` to `CODE_LINK_SCRIPT`, are removed; the codes themselves are unchanged | `quillmark-docx` Rust API | Use the variant, `quillmark_docx::notice::Code::FontNotEmbedded.as_str()`; `CODE_HINT_UNCHECKED` was `Code::HintMisused` |
