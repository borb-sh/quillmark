# 0.140 → 0.141 — `quillmark_docx::lower`'s code constants are gone

## Rust

`quillmark_docx::lower` no longer exports the `CODE_*` string constants, from `CODE_FONT_NOT_EMBEDDED` to `CODE_LINK_SCRIPT`. Each repeated a `quillmark_docx::notice::Code` variant's string, and the diagnostic codes themselves are unchanged. Spell a code through its variant:

```rust
quillmark_docx::lower::CODE_FONT_NOT_EMBEDDED       // before
quillmark_docx::notice::Code::FontNotEmbedded.as_str()   // after
```

`CODE_HINT_UNCHECKED` was `Code::HintMisused`.
